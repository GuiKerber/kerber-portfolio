Internal reference

Design system

Tokens, type styles and components behind this site. Primitive tokens hold raw values; semantic tokens give them a role; components only use semantic tokens. Values on this page are read live from css/tokens.css.

01 Tokens 02 Color 03 Typography 04 Space 05 Shape 06 Motion 07 Layers 08 Components 09 Images

01 Tokens

Two layers, one direction

Primitives are raw values named by scale: --neutral-100, --space-4, --font-size-600. Only tokens.css reads them.

Semantic tokens are named by role and point to a primitive: --color-bg-inverse → --neutral-100. Components use these, so changing a role means editing one line.

The spacing scale (--space-N = N × 4px) is used directly. The only literals left in component CSS are em and % ratios and sub-4px icon geometry.

03 Typography

Three families, one weight

TokenFamilyUse
--font-displayFamiljen GroteskTitles, headings, numbers, caps labels, pills
--font-bodyInter TightBody copy

Everything is set in Regular (400). Medium (500) is only used for the logo word. Classes .display, .heading, .caps and .mono carry family, tracking and line height; the component sets the size.

There is no drop shadow anywhere. Depth comes from the dark and light surfaces, hairlines and motion.

06 Motion

Quick UI, slow scenes

--ease
--ease-out

UI transitions stay between 150 and 300ms. Scroll-driven scenes (strips, horizontal work, spiral) follow the scroll instead of a duration. With reduced motion on, every animation is cut and the content shows in its final state.
