Analytics platform for supply chain managers at large retail chains — transforming 200+ data sources into clear, actionable decisions in real time.

Case structure

Analytics dashboard for operations managers at retail chains with 50+ stores. The product needed to integrate 200+ data sources and present them in a way that a non-technical manager could make confident decisions.

CompanyRetailIQ (SaaS B2B)
Duration5 months · 2024
RoleProduct Designer · Data UX
Team2 designers, 2 data engineers, 6 devs
UsersOperations managers, C-level

The existing product was a static report generated weekly as a PDF. Managers were making decisions with data 7 days old. The goal was to replace this with a real-time dashboard — without increasing perceived complexity.

  • Data came from 200+ sources: ERP, WMS, POS, manual spreadsheets
  • Managers were not "data people" — most had no analytics background
  • High cost of error: a wrong inventory decision could cause R$2M in losses
  • Previous product had an NPS of 18 with enterprise clients

Shadowing 12 managers over a working week. Finding: managers didn't want more data — they wanted to know "what to do now".

  • Managers spent 3h/day interpreting data that others had collected
  • The most frequent decisions fell into 3 types: replenish stock, redistribute between stores, escalate alerts
  • No manager used more than 4 metrics regularly — despite having access to 80+
  • Core insight: the product should recommend actions, not just display data

We worked alongside the data engineers to build a model around "decisions", not metrics. Every piece of data surfaced in the UI had to answer a specific question for a specific manager profile.

  • 3-level taxonomy: Alerts → Status → History
  • Urgency score automatically calculated for each alert
  • Visualizations adapted to role: operational, regional, C-level

An alert-driven dashboard with 3 views: the urgent actions feed, the current status panel, and the historical analysis module. The visual hierarchy was built to guide the manager's eye toward what matters.

  • Home page = prioritized list of "recommended actions"
  • Traffic-light color system: green (ok), yellow (attention), red (urgent)
  • Simplified charts: sparklines, bars — no pies or radars
  • Compact mode for C-level: KPIs and weekly changes only

Phased rollout: 3 pilot clients over 8 weeks, then expansion to 40 enterprise clients. The product became the main argument for contract renewals.
