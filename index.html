ABOUT ME

Senior Product Designer with 15+ years of experience designing complex digital products across Fintech, SaaS, AI, and Gaming.

Product Strategy
& UX Structure

[ 01 ]

Before starting any project, I like to run stakeholder interviews to understand the business and user goals behind it. From there I define the overall structure and the minimum requirements that make the product viable. Only then do I move to the next step.

Product Interface Design
& Vibe coded prototype

[ 02 ]

I've been skipping low-fidelity wireframes and going straight into Figma and Claude Code to explore designs. While Claude Code works through my prompt, I start from a blank frame myself, then judge which result is stronger and iterate on top of that.

Design system
& Project Handoff

[ 03 ]

Finally, I deliver a complete design system with variables in Figma, plus an HTML file wired to the Claude Code prototype. Both act as a source of truth for the design, and both are kept in sync.
